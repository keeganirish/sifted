      Welcome to Sifted

      Sifted fuses noisy measurements from several sensors into one picture of what is out there. It decides which measurements belong to which object, estimates where each object is going, and shows how sure it is.

      1. Pick a scenario of simulated aircraft, radar and camera, and press Run.
      2. Watch the map. Each dot is a track; the circle is its uncertainty, the line its heading.
      3. Break things. Add packet loss, an outage or a failing sensor, and see the tracker cope.
      4. Replay any run from its recording and verify the output is bit-for-bit identical.
